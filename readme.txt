== Description ==

Adwa is a lightweight, accessible, and flexible block theme built for Full Site Editing (FSE), Gutenberg, and the WordPress Site Editor.

Designed with modern WordPress standards, Adwa provides global styles, block patterns, style variations, and a clean editing experience using native WordPress blocks.

The theme focuses on performance, accessibility, responsive design, and creating a strong foundation for blogs, portfolios, business websites, and online stores.

== Features ==

* Full Site Editing support.
* Built using native WordPress blocks.
* Global styling powered by theme.json.
* Custom block patterns.
* Style variations.
* Responsive design.
* Accessibility-focused development.
* Lightweight performance-focused architecture.
* Translation-ready.

== Installation ==

1. Upload the Adwa folder to the /wp-content/themes/ directory.
2. Activate Adwa through Appearance > Themes.
3. Customise your website using Appearance > Editor.

== Accessibility ==

Adwa follows WordPress accessibility best practices and aims to provide an inclusive experience for all users.

Accessibility features include:

* Keyboard-friendly navigation.
* Visible focus indicators.
* Responsive typography.
* Reduced motion support.
* Semantic WordPress block markup.
* Consideration for readable colour contrast.
