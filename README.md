# Adwa Theme

A lightweight WordPress block theme built for Full Site Editing (FSE), Gutenberg, and the WordPress Site Editor.

## Features

- Full Site Editing support
- Block patterns
- Style variations
- Responsive design
- Accessibility-ready
- Translation-ready
- WooCommerce compatible
- Performance focused

## Requirements

- WordPress 6.5+
- PHP 7.4+

## Installation

1. Download the theme
2. Upload to `/wp-content/themes/adwatheme`
3. Activate through Appearance → Themes
